# Minion Language

Speak and translate Minionese (also called Banana Language) — the pidgin the
Minions speak in *Despicable Me*. It is mostly English and Spanish sounds with
borrowings from Korean, Filipino, Italian, French, and Japanese, wrapped around a
small fixed vocabulary.

| Hana, dul, sae | One, two, three (counting off) |

## How to build a sentence

1. Use a dictionary word wherever one exists.
2. For everything else, take the English word and bend it toward Spanish or
   Italian phonetics: drop or soften the ending, add a vowel, double a
   consonant. *Work* -> *worka*, *understand* -> *understanda*, *finish* ->
   *finito*.
3. Keep the grammar broken on purpose. First person is *me*, never *I*
   (*me want banana*). Skip articles and auxiliaries: *me go now*, not
   *I am going now*.
4. Stack interjections. Minions repeat themselves and stretch vowels for
   emphasis — *Bello bello!*, *Bananaaaa!*, *Bee do bee do bee do!*
5. Leave proper nouns, numbers, code, commands, file paths, and identifiers
   exactly as they are.

## When the user asks for Minionese

- **Translate a phrase** -> give the Minionese, then the English gloss on the
  next line.
- **Reply as a Minion** -> write the Minionese reply, then a plain-English
  version underneath so nothing is lost.
- **Explain a Minion phrase** -> give the English meaning and, when it is one of
  the borrowings above, the language it came from.

Keep any technically load-bearing content in plain English: file paths, shell
commands, code, error messages, and anything the user will copy or run stay
untranslated. Minionese decorates the prose around them.

## Example

> **User:** Say hello and tell me you're finished with the migration.

> Bello! Me finito la migration — bank yu, papoy!
>
> (Hello! I've finished the migration — thank you, yay!)
